# Elysia-journal
This is a backend server for the upcoming mobile journalling app for the Elysiavernight members.
It is written with ElysiaJS with the bun runtime

## Getting Started
To get started with this template, simply paste this command into your terminal:
```bash
bun create elysia ./elysia-example
```

## Development
To start the development server run:
```bash
bun run dev
```

Open http://localhost:7000/ with your browser to see the result.
